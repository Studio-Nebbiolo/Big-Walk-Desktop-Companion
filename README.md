# Magic School Companion

작업표시줄 위를 돌아다니는 동글동글한 데스크탑 친구들. Electron 앱이다.

## 실행

```bash
npm install
npm start
```

설치 파일 만들기: `npm run dist:win` (Windows, NSIS + 포터블), `npm run dist:mac`.

## 사용법

- 친구들은 작업표시줄 윗면에서 걷고, 쉬고, 앉고, 손을 흔든다. 마주치면 서로 인사도 한다.
- **클릭**하면 점프, **드래그**하면 들어 올려서 던질 수 있다. 세게 던지거나 높이서 떨어뜨리면 엉덩방아를 찧고 머리 위로 별이 돌며 한동안 헤롱헤롱한다.
- 가끔 바닥에 **무전기 · 확성기 · 라디오**가 떨어진다. 친구들이 주워서 들고 다니다가 무전기를 귀에 대거나, 확성기로 외치거나, 라디오를 튼다. 한참 들고 다니면 내려놓는다.
- **더블클릭**하거나 트레이 아이콘을 누르면 꾸미기 창이 열린다.
- **우클릭**하면 색 바꾸기 / 삭제 메뉴가 나온다.
- 꾸미기 창에서는 친구마다 **머리 · 몸통(목과 팔) · 다리(아래 공과 다리)** 세 부분의 색을 따로 고른다. 모든 친구는 같은 비율, 같은 크기다. 전체 속도와 크기, 소품 켜기/끄기, 멈추기, 시작 프로그램 등록도 여기서 한다.
- 친구는 최대 20명까지. 설정은 사용자 데이터 폴더의 `settings.json`에 저장된다.

## 색상

게임 속 페인트 보드의 7열 × 3행, 21가지 색만 쓴다 (하단 금색 · 흰색 · 갈색은 제외).
값은 `src/shared/palette.js`에 있고, 설정 파일에 팔레트 밖의 색이 들어오면 무시된다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 작업표시줄 위 투명 창, 트레이, 설정 저장, IPC |
| `src/preload.js` | 렌더러에 노출하는 API |
| `src/shared/palette.js` | 21색 팔레트와 부위 정의 |
| `src/shared/character.js` | 캐릭터 행동(상태 머신 · 물리)과 캔버스 그리기 |
| `src/shared/items.js` | 무전기 · 확성기 · 라디오 소품 |
| `src/renderer/companion.*` | 친구들이 사는 투명 창 |
| `src/renderer/settings.*` | 꾸미기 창 |

투명 창은 캐릭터가 없는 곳에서는 마우스가 그대로 통과한다. 작업표시줄이 아래가 아니거나 자동 숨김이면 화면 맨 아래를 땅으로 쓴다.
