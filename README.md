# Big Walk Companion

작업표시줄 위를 돌아다니는 동글동글한 데스크탑 친구들.
House House 의 게임 *Big Walk* 캐릭터에서 영감을 받아 만든 비공식 팬 프로젝트이며, Electron 앱이다.

## 받아서 쓰기 (Windows)

저장소의 **Releases** 페이지에서 최신 버전을 받는다.

- `BigWalkCompanion-<버전>-portable.exe`: 설치 없이 더블클릭으로 바로 실행.
- `BigWalkCompanion-<버전>-setup.exe`: 설치 프로그램 (시작 메뉴 · 바탕화면 바로가기).

코드 서명이 없어서 처음 실행할 때 "Windows의 PC 보호" 경고가 뜨면 **추가 정보 → 실행** 을 누른다.

## 개발

```bash
npm install
npm start
```

배포 파일 만들기: `npm run dist:win` (Windows, NSIS + 포터블), `npm run dist:mac`.

### 릴리스

`package.json` 의 `version` 을 올리고 같은 버전의 태그(`v0.2.0` 등)를 푸시하거나 Actions 탭에서 Release 워크플로를 수동 실행하면,
GitHub Actions(`.github/workflows/release.yml`)가 Windows 에서 exe 를 빌드해 Releases 에 올린다.

## 사용법

- 친구들은 작업표시줄 윗면에서 걷고, 쉬고, 앉고, 손을 흔든다. 마주치면 서로 인사도 한다.
- 걸을 때는 팔을 구부려 허리 높이에 두고, 한 걸음마다 통통 튀며 가볍게 걷는다.
- **클릭**하면 점프, **드래그**하면 들어 올려서 던질 수 있다. 세게 던지거나 높이서 떨어뜨리면 엉덩방아를 찧고, 머리 위로 별이 돌고 눈이 소용돌이가 되어 한동안 헤롱헤롱한다.
- 가끔 선 채로, 또는 앉은 채로 고개를 푹 숙이고 꾸벅꾸벅 존다 (눈은 U 모양).
- 가끔 바닥에 **무전기 · 확성기 · 라디오 · 신호탄 총**이 떨어진다. 친구들이 주워서 들고 다니다가 무전기를 귀에 대거나, 확성기로 외치거나, 라디오를 귀 옆에 들고 음악을 틀거나, 신호탄을 하늘로 쏘아 올린다(꼭대기에서 펑 터진다). 한참 들고 다니면 내려놓는다.
- 가끔 작업표시줄에 **빨간 오뚜기**가 떨어진다. 친구들이 모두 모여 주변에 겹치지 않게 자리를 잡고, 신기하다는 듯이 손가락질하고 손뼉 치고 머리를 긁적인다.
  - 오뚜기(라디오만 한 크기)를 **클릭**하면 휘청이고, 친구들이 "야호!" 하듯 두 손을 들고 가볍게 폴짝 뛴다. 연타해도 한 번 뛴 친구는 잠깐 쉬었다 다시 뛴다. 머리 위 고리가 다 차도록 **20번** 클릭하면 펑! 하고 **수집**된다.
  - 3분 동안 아무도 오뚜기를 건드리지 않으면 신호탄을 든 친구가 하늘로 쏜다. 아무도 안 들고 있으면 바닥의 신호탄을 주워 와서, 그것도 없으면 떨어진 신호탄을 주워 와서 쏜다.
  - 10분 동안 못 모으면 조용히 사라진다. 모은 개수는 메뉴 첫 화면과 트레이 메뉴에서 볼 수 있다.
- **숨기기 단축키**(기본 `Ctrl + Alt + H`)를 누르면 친구들이 바로 숨고, 다시 누르면 나타난다. 메뉴의 "단축키 설정"에서 바꾸거나 끌 수 있다.
- 트레이 아이콘을 누르면 **메뉴**가 열린다: 캐릭터 커스터마이징 · 단축키 설정 · 나가기. 친구를 **더블클릭**하면 바로 그 친구의 커스터마이징 화면이 열린다.
- **우클릭**하면 색 바꾸기 / 공유 코드 복사 / 삭제 메뉴가 나온다.
- 꾸미기 창에서는 친구마다 **머리 · 몸통(목과 팔) · 다리(아래 공과 다리)** 세 부분의 색을 따로 고른다. 모든 친구는 같은 비율, 같은 크기다.
- "모두에게 적용"에서 걷는 속도, 전체 크기, 서로 인사하기, 소품, 빨간 오뚜기, 발밑 그림자, 멈추기, 시작 프로그램 등록을 바꾼다.
- **언어**: 기본은 Windows 표시 언어를 따른다. 지원하는 언어는 영어 · 한국어 · 일본어 · 중국어(간체/번체) · 스페인어 · 포르투갈어 · 프랑스어 · 독일어 · 이탈리아어 · 러시아어이고, 그 밖의 언어면 영어로 보인다. 메뉴 첫 화면 오른쪽 위 🌐 에서 직접 고를 수 있다.
- 친구는 최대 20명까지. 설정은 사용자 데이터 폴더의 `Big Walk Companion/settings.json` 에 저장된다.
  예전 이름(Magic School Companion)으로 저장된 설정이 있으면 처음 실행할 때 자동으로 옮겨 온다.

## 공유 코드

꾸미기 창에서 친구마다 `BW1-` 로 시작하는 코드가 보인다. 이름과 세 부위 색이 들어 있다.

- **보내기**: "복사"를 누르거나 친구를 우클릭해서 "공유 코드 복사".
- **받기**: "🔗 코드로 친구 추가"에 붙여넣고 "추가".
- 코드에 검사값이 있어서 오타가 나거나 일부만 복사된 코드는 거절한다.
- 예전 이름 시절의 `MS1-` 코드도 그대로 받을 수 있다.

## 색상

게임 속 페인트 보드의 7열 × 3행, 21가지 색만 쓴다 (하단 금색 · 흰색 · 갈색은 제외).
값은 `src/shared/palette.js` 에 있고, 설정 파일에 팔레트 밖의 색이 들어오면 무시된다.
색 **순서**는 공유 코드에 들어가므로 바꾸면 안 된다 (색 값 조정은 괜찮다).

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/main.js` | 작업표시줄 위 투명 창, 트레이, 숨기기 단축키, 설정 저장, 클립보드, IPC |
| `src/preload.js` | 렌더러에 노출하는 API |
| `src/shared/palette.js` | 21색 팔레트와 부위 정의 |
| `src/shared/character.js` | 캐릭터 행동(상태 머신 · 물리)과 캔버스 그리기 |
| `src/shared/items.js` | 무전기 · 확성기 · 라디오 · 신호탄 소품과 발밑 그림자 |
| `src/shared/daruma.js` | 빨간 오뚜기 (흔들림 · 클릭 · 수집 효과) |
| `src/shared/i18n.js` | 화면 글자 번역 (11개 언어)과 시스템 언어 고르기 |
| `src/shared/sharecode.js` | 친구 공유 코드 만들기 / 읽기 |
| `src/renderer/companion.*` | 친구들이 사는 투명 창 (오뚜기 모이기 · 신호탄 미션 포함) |
| `src/renderer/settings.*` | 메뉴 창 (커스터마이징 · 단축키 · 나가기) |

투명 창은 캐릭터가 없는 곳에서는 마우스가 그대로 통과한다. 작업표시줄이 아래가 아니거나 자동 숨김이면 화면 맨 아래를 땅으로 쓴다.
